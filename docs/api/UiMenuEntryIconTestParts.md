# UiMenuEntryIconTestParts

Returned by `ui.menuEntryIcon(entry)`. **column** locates the box allocated
to the supplied entry’s icon, including a reserved empty column. **icon**
locates the actual artwork inside that box when supplied. The mapping
excludes columns belonging to nested entries. Check alignment, rendered
artwork and accessibility on the relevant part.

See [presentation mappings](presentation-parts.md).
