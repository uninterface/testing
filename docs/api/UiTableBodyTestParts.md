# UiTableBodyTestParts

Returned by `ui.tableBody(table)`. **body** locates the row host and, when
native markup separates empty content from rows, the region owning both.
**scrollSurface** locates the rendered scrolling part. **emptyState** and
**errorState** locate the table’s empty and initial failure content in its
collection scope. Use the column-header API for the actual sorted header.

See [presentation mappings](presentation-parts.md).
